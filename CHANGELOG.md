# Changelog

## 0.1.1

- Keep transcripts readable, searchable, and copyable while AI analysis runs inside its own panel.
- Continue recording across page navigation, with a draggable, always-on-top desktop recording widget for pause, resume, stop, and return controls.
- Preserve recording controls and elapsed time independently of the currently viewed meeting.
- Improve recording waveforms, loading animations, audio-device handling, and audio shutdown reliability.
- Improve model selection, provider configuration, transcription configuration, and error messages.
- Refine bilingual meeting analysis and Word export formatting.

Validation: 260 automated tests passed, ESLint passed, and the Windows release build includes the native audio helper.
